Development Setup¶

This guide covers setting up a development environment for OpenEnlighten.

Prerequisites¶

Ensure you have the following installed:

  • Python 3.12+: For backend development

  • Node.js 18+: For frontend development

  • Git: For version control

  • VS Code: Recommended IDE with workspace configuration

Development Environment¶

1. Clone and Setup:

git clone <repository-url>
cd OpenEnlighten

2. Backend Setup:

cd enlweb-api
python -m venv venv

# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate

pip install -r requirements.txt

3. Frontend Setup:

cd enlweb-client
npm install

4. VS Code Workspace:

Open the workspace file for the best development experience:

code OpenEnlighten-ENLWeb-API.code-workspace

VS Code Configuration¶

This project provides a complete IntelliJ-like experience in VS Code with full Python development integration.

Auto-Configuration: VS Code automatically detects and configures:

  • Virtual environment (./enlweb-api/venv/)

  • Python paths and imports

  • Debugging and testing

  • Linting and formatting

Consolidated Tasks (Ctrl+Shift+P → “Tasks: Run Task”):

All tasks are centralized in the top-level .vscode/tasks.json file.

Quick Start Tasks:

  • Start Both Servers - One-click startup for both FastAPI and Angular

  • Start FastAPI Server (Shared Config) - Recommended, uses shared config, loads plugins, port 8081

  • Angular Dev Server - Starts Angular development server with HMR

Backend Tasks (FastAPI):

  • Start FastAPI Server (Local Config) - Local config only, port 8080

  • Run FastAPI Tests - Execute pytest suite with coverage

  • Install FastAPI Dependencies - Install Python requirements

  • Lint FastAPI Code - Run flake8 linting

  • Format FastAPI Code - Run black code formatter

Frontend Tasks (Angular):

  • Angular Build Production - Build for production deployment

  • Run Angular Tests - Execute Karma/Jasmine test suite

  • Install Angular Dependencies - Run npm install

  • Lint Angular Code - Run Angular linting

Compound Tasks:

  • Run All Tests - Execute both FastAPI and Angular tests

  • Install All Dependencies - Install both Python and npm packages

Debug Configurations (F5 Menu):

  1. FastAPI Development Server - Debug main server (default)

  2. FastAPI Server (Custom Port) - Server on port 8000

  3. Python: Current File - Debug currently open Python file

  4. Python: Run Tests - Debug test execution

Code Quality Features:

Auto-Configured:

  • ✅ Black: Code formatting (auto-format on save)

  • ✅ Flake8: Linting and style checking

  • ✅ isort: Import sorting

  • ✅ MyPy: Type checking (if configured)

IntelliSense Features:

  • ✅ Auto-completion and imports

  • ✅ Type hints and documentation

  • ✅ Error squiggles and suggestions

  • ✅ Refactoring support

Terminal Integration:

  • Integrated Terminal: Ctrl+Shift+

  • Virtual environment auto-activates

  • PYTHONPATH pre-configured

  • All Python commands use venv automatically

Virtual Environment Setup¶

What’s Available:

  • Location: ./enlweb-api/venv/

  • Python Version: 3.12.8

  • All Dependencies: Installed from requirements.txt

Helper Scripts (util/ directory):

  • activate_venv.bat - Activates the virtual environment in command prompt

  • run_server.bat - Starts the FastAPI development server (local config)

  • run_server_shared_config.bat - Starts server with shared configuration

  • run_tests.bat - Runs the pytest test suite

Usage Options:

Option 1: Helper Scripts (Easiest):

# Start Development Server (Shared Config)
util\run_server_shared_config.bat

# Run Tests
util\run_tests.bat

# Interactive Session
util\activate_venv.bat

Option 2: PowerShell Commands:

# Navigate to Project
cd "C:\path\to\your\OpenEnlighten\enlweb-api"

# Any Python command using venv
.\venv\Scripts\python.exe [command]

# Install packages
.\venv\Scripts\pip.exe install [package_name]

# Start server (shared config)
cd src
$env:PYTHONPATH = "$PWD"
..\venv\Scripts\python.exe dev_server.py --config-dir ../../config --host 127.0.0.1 --port 8081

# Run tests
.\venv\Scripts\python.exe -m pytest tests/ -v

Development Workflow¶

Daily Development:

  1. Start Servers: Use VS Code task “Start Both Servers” or manual commands

  2. Make Changes: Edit code with auto-formatting and linting

  3. Test Changes: Run unit tests and integration tests

  4. Debug: Use VS Code debugger for both frontend and backend

Backend Development:

# Start with debugging
cd enlweb-api/src
python dev_server.py --config-dir ../../config --host 127.0.0.1 --port 8081

Frontend Development:

# Start with hot reload
cd enlweb-client
npm start

Testing¶

Backend Tests:

cd enlweb-api
python -m pytest tests/ -v --cov=app

Frontend Tests:

cd enlweb-client
npm test

Integration Tests:

# Start both servers first, then run integration tests
npm run test:e2e

Code Quality¶

Python (Backend):

# Linting
flake8 src/

# Formatting
black src/ tests/

# Type checking
mypy src/

TypeScript (Frontend):

# Linting
npm run lint

# Formatting
npm run format

# Build check
npm run build

Development Tools¶

Useful Commands:

# Backend dependency management
pip-compile requirements.in  # Update requirements.txt

# Frontend dependency management
npm audit fix  # Fix security vulnerabilities
npm update     # Update dependencies

Database/Data Management:

# Set data path
set ENL_DATA_PATH=C:\path\to\your\data

# Or use .env file in project root
echo ENL_DATA_PATH=C:\path\to\your\data > .env

Debugging¶

Backend Debugging:

  • Use VS Code debugger with launch configuration

  • Add breakpoints in Python code

  • Inspect variables and call stack

  • Use interactive debug console

Frontend Debugging:

  • Use browser developer tools

  • Angular DevTools extension

  • VS Code debugging for TypeScript

  • Network tab for API debugging

Configuration Debugging:

  • Check YAML syntax validation

  • Verify file paths in configuration

  • Check plugin loading in server logs

  • Test configuration with minimal setup
