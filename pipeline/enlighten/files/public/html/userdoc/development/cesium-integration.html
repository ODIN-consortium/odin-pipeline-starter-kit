Cesium Integration¶

This guide covers the integration of Cesium for 3D earth visualization in the Angular client.

Overview¶

The Angular client integrates Cesium for 3D earth visualization with configurable map layers. The integration supports various layer types including OpenStreetMap, satellite imagery, and custom terrain providers.

Configuration Structure¶

Layer Configuration¶

Cesium layers are configured in client_config.yaml:

cesiumLayers:
  base:
    - type: "OpenStreetMap"
      name: "OpenStreetMap"
      tooltip: "OpenStreetMap standard layer"
      iconUrl: "i/icons/osm.png"
      options: {}

    - type: "NaturalEarthII"
      name: "Natural Earth II"
      tooltip: "Natural Earth II satellite imagery"
      iconUrl: "i/icons/ne.png"
      options: {}

Viewer Configuration¶

Cesium viewer widgets can be configured:

cesiumViewer:
  homeButton: false
  sceneModePicker: false
  baseLayerPicker: true
  geocoder: true
  navigationHelpButton: false
  animation: false
  timeline: false
  fullscreenButton: true
  vrButton: false

Layer Types¶

OpenStreetMap¶

Standard street map layer:

- type: "OSM"
  name: "OpenStreetMap"
  tooltip: "OpenStreetMap collaborative map\nhttp://www.openstreetmap.org"
  iconUrl: "assets/Cesium/Widgets/Images/ImageryProviders/openStreetMap.png"
  options:
    url: "https://a.tile.openstreetmap.org/"
    credit: "OpenStreetMap contributors"
    # See: https://cesium.com/learn/cesiumjs/ref-doc/OpenStreetMapImageryProvider.html

Natural Earth II¶

Satellite imagery layer:

- type: "NaturalEarthII"
  name: "Natural Earth II"
  tooltip: "Natural Earth II satellite imagery"
  iconUrl: "i/icons/ne.png"
  options: {}

Terrain Providers¶

Elevation data configuration:

cesiumLayers:
  terrain:
    - type: "Ellipsoid"
      name: "WGS84 Ellipsoid"
      tooltip: "WGS84 Ellipsoid terrain"
      # See: https://cesium.com/learn/cesiumjs/ref-doc/EllipsoidTerrainProvider.html

Custom Layers¶

Web Map Service (WMS) layers:

- type: "WMS"
  name: "Custom WMS Layer"
  tooltip: "Web Map Service layer"
  iconUrl: "i/icons/wms.png"
  options:
    url: "https://example.com/wms"
    layers: "layer_name"
    parameters:
      service: "WMS"
      version: "1.1.1"
      request: "GetMap"
    # See: https://cesium.com/learn/cesiumjs/ref-doc/WebMapServiceImageryProvider.html

Layer Configuration Reference¶

Each layer supports the following configuration options:

Required Fields:

  • type: Layer type (OSM, WMS, Tile, etc.)

  • name: Display name for the layer

Optional Fields:

  • tooltip: Tooltip text (supports \n for newlines)

  • iconUrl: Path to layer icon image

  • options: Provider-specific layer options

Provider Options:

Provider-specific options depend on the Cesium provider type. Refer to the Cesium documentation for detailed configuration:

  • OpenStreetMapImageryProvider

  • WebMapServiceImageryProvider

  • EllipsoidTerrainProvider

Integration Details¶

Configuration Loading¶

The Angular frontend loads Cesium configuration through the API:

  1. Backend serves configuration via API endpoint

  2. Frontend loads configuration during application initialization

  3. Cesium viewer is configured with loaded settings

  4. Layers are dynamically added to the viewer

Icon Management¶

Layer icons should be placed in the Angular client’s public directory:

enlweb-client/public/i/icons/
├── osm.png
├── ne.png
└── wms.png

Troubleshooting¶

Common Layer Issues¶

Gray/blank layers:

  • Remove non-working layer configurations

  • Check network connectivity to layer services

  • Verify layer URLs and parameters

Missing layers:

  • Check YAML syntax and indentation

  • Ensure required fields are present

  • Validate layer type spelling

No base picker:

  • Ensure baseLayerPicker: true in viewer config

  • Verify at least one base layer is configured

  • Check for JavaScript console errors

Configuration Validation¶

The backend validates YAML structure using Pydantic models:

  • Layer structure must match expected format

  • All required fields must be present

  • Invalid configurations will cause startup errors

  • Check server logs for validation messages

Development Notes¶

Configuration Changes:

  • Layers are loaded from shared /config/client_config.yaml

  • Changes require server restart to take effect

  • Configuration is validated on server startup

Icon Resources:

  • Icon files should be placed in enlweb-client/public/i/icons/

  • Use standard image formats (PNG, SVG, JPG)

  • Recommended icon size: 18x18 pixels for best appearance

Layer Development:

  • Test new layer configurations in development environment

  • Use minimal configuration first, then add advanced options

  • Refer to Cesium documentation for provider-specific parameters

  • Monitor browser console for Cesium-related errors

Performance Considerations¶

  • Layer Count: Limit the number of base layers to improve UI performance

  • Tile Caching: Configure appropriate caching headers on tile services

  • Network Optimization: Use CDN or local tile services when possible

  • Memory Management: Monitor browser memory usage with multiple layers
