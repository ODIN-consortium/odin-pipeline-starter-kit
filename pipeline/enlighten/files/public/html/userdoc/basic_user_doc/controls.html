Mouse and keyboard controls¶

This page describes all mouse interactions for the 2D scatter plot and line chart panels. Navigation in the 3D Cesium globe uses its own controls, described in 3D Cesium globe.

2D scatter plots and line charts¶

The table below summarises every mouse action in a 2D plot panel:

Mouse action

Effect

Left-drag (no modifier)

Pan — moves the visible area in X and Y.

Alt + left-drag or Shift + left-drag

Draw a rectangular selection. Points inside the rectangle are highlighted; all linked plots on the page update immediately. The rectangle is shown as a dashed white outline. Drag again to replace the selection.

Left-drag on existing selection (no modifier)

Move the selection rectangle without changing its size.

Ctrl + left-drag (horizontal)

Change dot / point size. Drag right to make dots larger, left to make them smaller. The size is preserved when you switch datasets.

Right-drag

Zoom in or out, centred on the point where you pressed the mouse button. Dragging up/right zooms in; dragging down/left zooms out.

Tip

Selections always combine with any axis filters that are already active. Set a coarse time window with an axis drag first, then use Alt-drag to highlight a specific cluster of points.

Clearing selections and filters¶

  • Drag the axis handle back to its full range to remove a single axis filter.

  • Open the main menu (⋮) and choose Clear all filters to remove everything at once.

3D Cesium globe¶

The Cesium 3D view uses the standard Cesium navigation model:

Mouse action

Effect

Left-drag

Rotate the globe / pan the camera.

Right-drag or scroll wheel

Zoom in / out.

Middle-drag (or Ctrl + left-drag)

Tilt / look around.

Double-click

Zoom to the clicked location.

Data selections made in 2D plots are shown as highlighted points overlaid on the globe. The Cesium view itself does not have a separate selection mechanism — selections are always driven from the 2D plots.
